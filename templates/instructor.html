Day panels

Variables

Named values other elements can bind to. Every number below can be picked as a progress bar's Current or Total from the Visual editor (right-click the bar › "Bind variables"), on any page. "Total days" and "Days progressed" always exist and can't be removed - rename them however reads best, or add your own below.

Extra attachments

Files here show up on every student's dashboard, outside the day panels.

Gallery

Photos and clips shown on the public gallery page, grouped into named directories. A directory doesn't have to be a year — call one whatever you like, and rename it here at any time. Each one gets its own tile in the gallery page's directory rail, and can be shown by its own image pane in the Visual editor.

Clips are always muted and looping. With any of the last two on, clicking a clip works its player instead of moving to the next image — the arrows and the rest of the pane still flip through the directory as usual.

Landing page

Everything on this page is edited in place in the Visual editor now. The one thing left here is the tooltip below: it only exists while someone is hovering over an Apply Now button, so there's no element in the editor to click on.

Objects

Reusable bundles of elements (a tile, a countdown, a whole navbar) built in their own mini editor, then dropped onto the page from the Visual editor's right-click "Add element" menu. Shared with every staff member; only the ta who added one can remove it.
